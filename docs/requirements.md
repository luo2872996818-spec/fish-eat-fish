## 1. 项目概述（一句话）

做一个**手机浏览器打开链接就能玩**的「大鱼吃小鱼」小游戏：吃比自己小的鱼长大，
躲开比自己大的鱼，撞上就掉命。不用安装 App，把链接发给别人就能一起玩。

## 2. 目标用户

| 问题 | 回答 |
|---|---|
| 谁会玩？ | 自己，以及收到链接的朋友、同学 |
| 用什么玩？ | **手机浏览器为主**（Safari / 安卓 Chrome / 微信内置浏览器） |
| 电脑能不能玩？ | **能，用鼠标**。但不是主要场景，键盘操作只是留好接口 |
| 需要安装什么吗？ | 不需要。打开链接即玩；可以「添加到主屏幕」当 App 用 |
| 需要联网吗？ | 首次打开需要（下载几十 KB 的代码），之后就都在本地跑 |

## 3. 核心功能（第一版必须有）

### 功能 1：触摸控制游动
手指按在屏幕上，鱼朝手指的方向游过去；手指移动，鱼跟着转向。
**关键要求**：鱼要有**加速度和阻尼**（不是瞬间跟到手指位置），这样才有"游"的感觉。
松手后鱼会滑行一段再停下。撞到屏幕边缘不会跑出去。

### 功能 2：吃小鱼长大
吃到比自己小的鱼 → 得分 + 体型变大。共 **5 个等级**（初始算第 1 级）。
满级之后继续吃只加分、不再变大。

### 功能 3：躲大鱼保命
撞上比自己大的鱼 → **掉 1 条命**，共 3 条命。掉命后有 **1.5 秒无敌时间**
（鱼身闪烁）—— 没有这个保护的话，一头扎进鱼群里会瞬间掉光三条命，玩家会觉得"莫名其妙就死了"。

### 功能 4：计分与难度上升
- 吃一条鱼得分，**越大的鱼分数越高**
- 随着等级提升和时间推移，画面里"大鱼"的比例从约 10% 涨到约 30%
  —— 这是让游戏耐玩、并且难度可控的**唯一旋钮**

### 功能 5：完整的一局流程
主菜单（点开始）→ 游戏中（顶部显示分数 / 生命 / 成长条）→
3 条命掉光 → 结束面板（本局分数 + 本机最高分 + 重新开始按钮）。
最高分存在手机本地（localStorage），关掉浏览器也不会丢。

## 4. 非功能性要求

| 要求 | 标准 |
|---|---|
| 平台 | 手机浏览器优先；竖屏横屏都要能玩；电脑鼠标也能玩 |
| 部署 | GitHub Pages 静态托管，**点开链接就能玩**，无需安装 |
| 性能 | 中端手机稳定 **55 FPS 以上**；不能出现"鱼瞬移穿过大鱼"的穿透 bug |
| 体积 | 首屏资源 < 200 KB，**零依赖、零构建**（不用 npm，不引第三方库） |
| 兼容 | 手机端适配：刘海安全区、地址栏伸缩、禁下拉刷新、禁双击缩放 |
| 可维护 | 所有可调数值集中在 `config.js`；代码带中文注释，按功能分文件夹 |

## 5. 不要做什么（重要！）

明确列出来，防止做到一半不断加需求：

- ❌ 滚动的大地图 / 关卡系统（第一版就是一屏）
- ❌ 联网排行榜、账号、后端服务（只存本机最高分）
- ❌ 音效和背景音乐
- ❌ 手绘美术素材（画面全部用 Canvas 代码画几何图形）
- ❌ 暂停、存档、继续上次进度
- ❌ 道具（加速冲刺、毒水母、护盾等）
- ❌ **PC 键盘操作的实际实现**（架构上留好接口，但这一版不做功能）
- ❌ 广告

> 这些不是"永远不做"，是"**这一版不做**"。等核心玩法跑通、你自己玩着觉得有意思了，
> 再从这里挑一个加进来。想加的时候，先回来更新这份文档。

## 6. 验收标准（怎么算做完了）

| 功能 | 验收方式 |
|---|---|
| 触摸控制 | 手机上手指拖动，鱼平滑跟随，方向正确；松手后滑行减速；撞边界停住不出去 |
| 吃小鱼 | 撞到小鱼后小鱼消失、加分、成长条上涨；攒够条数后鱼明显变大 |
| 躲大鱼 | 撞到大鱼掉一条命，鱼闪烁 1.5 秒，闪烁期间再撞不扣命 |
| 难度曲线 | 玩 2 分钟后画面里的大鱼明显比开局多 |
| 一局流程 | 能从菜单开始玩到 3 条命掉光，看到分数和最高分，点按钮重开 |
| 整体 | `node tools/check-deploy.mjs <线上地址>` 全部通过；手机上 55+ FPS |
